# Copyright and Submission Boundary

## 포함 가능한 자료

- MIT 라이선스 조건을 유지한 xv6-public 기반 코드
- 보존 자료에서 확인되는 본인의 커널 변경
- 포트폴리오 재구성 과정에서 새로 작성한 테스트와 문서
- 개인정보가 없는 실제 실행 결과

## 포함하지 않는 자료

- 강의 PDF와 과제 명세
- 교수 또는 조교가 제공한 테스트 코드
- 기존 제출 ZIP과 patch
- 시험문제와 수기 답안
- 개인정보가 포함된 소스, 파일명, 경로 또는 실행 화면
- Git 로그 및 설정을 포함한 과거 `.git` 디렉터리

## Attribution

기반 코드는 MIT PDOS의 xv6-public이며, 저장소의 `LICENSE`와 `UPSTREAM.md`를 유지합니다.
README와 포트폴리오에서는 전체 xv6를 직접 작성한 것으로 표현하지 않고, 변경한 커널
기능과 2026년 개선 범위를 구체적으로 구분합니다.

## 공개 전 확인

1. Git 첫 커밋 전에 개인정보와 자격증명을 검사합니다.
2. 삭제 예정 파일을 먼저 커밋하지 않습니다.
3. 제공 테스트와 과제 문구가 남아 있지 않은지 확인합니다.
4. 빌드 산출물을 `make clean`으로 제거합니다.
5. GitHub 공개 범위는 직무별 제출 가이드를 다시 확인한 후 결정합니다.
