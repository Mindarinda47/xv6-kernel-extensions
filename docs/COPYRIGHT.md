## 포함 가능한 자료

- MIT 라이선스 조건을 유지한 xv6-public 기반 코드
- 본인이 구현한 커널 변경
- 별도로 작성한 테스트와 설명 문서

- 강의 PDF와 과제 명세

- 시험문제와 수기 답안
- 개인정보가 포함된 소스, 파일명, 경로 또는 실행 화면
- Git 로그 및 설정을 포함한 과거 `.git` 디렉터리
